# Task Manager

A simple and responsive Task Manager application built using **React.js**. I created this project to practice my React development skills and understand how real-world task management applications work.

The application allows users to add tasks, view task details, manage priorities, and track task progress through a clean and user-friendly interface.

## Features

- **View Tasks:** Display all tasks in a structured table.
- **Add Tasks:** Create new tasks with the required details.
- **Task Details:** View complete information about individual tasks.
- **Task Status:** Track tasks as Pending, In Progress, or Completed.
- **Priority Management:** Set task priorities as Low, Medium, or High.
- **Progress Tracking:** Monitor task completion using a progress indicator.
- **Date Management:** Set start dates and deadlines for tasks.
- **Navigation:** Navigate between pages using React Router.

##  Technologies Used

- **React.js** – Building reusable UI components.
- **JavaScript (ES6+)** – Application functionality and logic.
- **HTML5** – Structuring the application.
- **CSS3** – Styling and responsive layout.
- **React Router DOM** – Handling page navigation.
- **Mockoon** – Creating a mock REST API to simulate backend functionality.
- **Fetch API** – Fetching and submitting task data.

## How Mockoon Works

Since this is a frontend project, I used **Mockoon** to simulate a backend REST API.

Mockoon provides sample task data and allows the application to perform API operations such as:
- GET – Fetch and display tasks.
- POST – Add new tasks.

This helped me understand how a frontend application communicates with an API without building an actual backend.

## Installation and Setup

Follow these steps to run the project on your local machine.

**1. Clone the repository**

```bash
git clone https://github.com/dalvisiddhesh508-sys/Task-Manager.git
```

**2. Navigate to the project folder**

```bash
cd Task-Manager
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Start Mockoon**

Open Mockoon, load your mock API environment, and start the server on port `3001`.

Make sure your tasks endpoint is available at:

```text
http://localhost:3001/tasks
```

Now open the local URL shown in your terminal to use the application.
